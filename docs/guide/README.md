# optopus studio guide

These pages take you from a fresh checkout to a model you can compare, share and hand over. Read
them in order the first time; later, jump to the one you need.

| Page | Read it when |
|---|---|
| [Getting started](getting-started.md) | you are installing the studio for the first time |
| [Your first session](first-session.md) | the studio is running and you want to solve something |
| [The interface](interface.md) | you wonder what a button, tab or banner does |
| [Projects, revisions and files](projects.md) | you want to know what the agent writes and where it is kept |
| [Troubleshooting](troubleshooting.md) | something does not work |
| [Development](development.md) | you are going to change the studio itself |

Sharing a project, packaging a model as an app and handing it to a customer as a Docker image are
described in the [README](../../README.md#sharing-a-project). The decisions behind the design are
in [`docs/adr/`](../adr/).
