このガイドは、リポジトリを手元に用意したところから、比較・共有・受け渡しができるモデルを作るまでを
案内します。初めてのときは順番に読み、その後は必要なページだけを開いてください。

| ページ | 読むとき |
|---|---|
| [はじめに](getting-started.md) | studio を初めてインストールするとき |
| [最初のセッション](first-session.md) | studio が動いていて、何かを解いてみたいとき |
| [画面の説明](interface.md) | ボタン・タブ・バナーの意味を知りたいとき |
| [プロジェクト・リビジョン・ファイル](projects.md) | エージェントが何を書き、どこに保存されるかを知りたいとき |
| [トラブルシューティング](troubleshooting.md) | うまく動かないとき |
| [開発](development.md) | studio 自体を変更するとき |

プロジェクトの共有、モデルのアプリ化、Docker イメージでの顧客への受け渡しは
[README](../../../README.md#sharing-a-project)(英語)に書かれています。設計上の判断は
[`docs/adr/`](../../adr/)(英語)にあります。
