# optopus studio

Chat-driven optimization on [optopus](https://github.com/trash-iine/optopus-py). Describe a task
in a chat; an agent models it, solves it with optopus, and draws the result on a canvas next to
the chat. The source, and how to install it, are at
[github.com/trash-iine/optopus-studio](https://github.com/trash-iine/optopus-studio).
